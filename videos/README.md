# Video scripts

One plain text file per page or lesson, written to be spoken by a
synthesia.io avatar. Target 60 to 90 seconds, which is roughly 150 to
200 words. Short sentences. No stage directions, the file is exactly
what gets read. When a video is produced, the page gets its `video:`
front matter block back (see project/page-model.md).

| Script | Page | Target |
|---|---|---|
| home.txt | / | 75 s |
