# Video scripts

One directory per video. `<name>.txt` is the full script, and
`<name>/scene-N.txt` are the same words split one file per scene, since
Synthesia's automatic scene split is unreliable. Paste each scene file
into its scene by hand. Written to be spoken. Target 60 to 90 seconds
total, roughly 150 to 200 words. Short sentences. No stage directions,
a file is exactly what gets read. When a video is produced, the page
gets its `video:` front matter block back (see project/page-model.md).
