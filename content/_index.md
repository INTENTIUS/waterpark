title: "water park"
---

Water park is a set of short lessons on letting an agent work on real infrastructure without having to trust it, built on the principles of [Accessible Ops](https://accessibleops.net).

It is a courses repo first. It is also the thing the courses work on. By the end of course 2 this repo owns its own AWS access as a repo anyone can send a pull request to, and an agent works that repo as a concierge and a watcher. A pattern you read about is an opinion. A pattern the thing you are reading runs on is a demonstration.

Course 1 is Fountain, the runtime that gives an agent a computer of its own. Course 2 builds the access repo and puts the agent on it. The pattern does not care which agent or which applier you use. This course pairs Fountain with Terraform because both are free and both run on a laptop.

See the [status page](status/) for what is checked by machinery versus what is only written down.
